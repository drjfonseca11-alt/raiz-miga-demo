# Raíz & Miga — demo de panadería y café

Demo estática de una panadería artesanal con masa madre, ingredientes orgánicos seleccionados y recetas sin azúcar añadida. La portada incluye testimonios de muestra, datos de contacto y un mapa integrado; las imágenes tienen una alternativa automática si una foto externa no carga.

- `index.html`: inicio, filosofía, destacados y ubicación.
- `catalogo.html`: catálogo en una página aparte, con filtros y búsqueda.
- `style.css`: estilos compartidos y diseño adaptable.
- `catalogo.js`: filtros y búsqueda del catálogo.
- `imagenes.js`: alternativa automática si alguna imagen externa no carga.

Los productos, precios, dirección y número de WhatsApp son ficticios para la demo. Las imágenes y tipografías se cargan desde internet.
